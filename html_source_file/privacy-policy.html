Privacy Policy

Last updated: October 1, 2026

Purpose

This application is a personal utility used to access and transfer files from my Google Drive using the rclone command-line application.

Google Drive Data

The application accesses Google Drive data only for the purpose of transferring files between my Google Drive account and my local storage.

Data Storage and Sharing

Google Drive data accessed through this application is not sold, shared, or distributed to third parties. The transferred files are stored on local storage controlled by me.

OAuth authentication credentials and tokens are used only to authenticate access to my Google Drive account.

Third-Party Services

This application uses Google's APIs to access Google Drive and uses rclone as the command-line client for transferring files.

Contact

This application is intended for personal use. For questions regarding this privacy policy, please contact the developer through the contact information available on this website.
